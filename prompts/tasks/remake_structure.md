# Task: remake structure (learning copy)

Given a description of a reference track's structure, rebuild an **original**
arrangement skeleton in the same shape — for learning, never a commercial remake.

Produce sections (intro, build, break, drop, outro) with bar ranges and the
actions per section: what enters, what leaves, which filters automate, where
energy rises and falls.

Output sections compatible with the `MusicalIdea.sections` schema. Keep all
musical content original; copy the *structure*, not the notes.
