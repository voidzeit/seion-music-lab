# Task: critique a loop

Given a `MusicalIdea` (and optionally its SEION score), return a short verdict
and a list of concrete fixes.

Check: harmony coherence, bass vs chords, density, tension, repetition/space,
style match, arrangement, editability.

Each fix = `{ target, change, reason }`. Be specific:
- "replace Cmaj7 with Em7 to keep it darker"
- "thin the arp to 2-3 notes per bar for more hypnotic space"

Tie advice back to the requested references and emotions.
